# 原视频候选分类复核

目的：先区分肉眼明确传播、明确局部活动、未见可信活动及不确定，再检查候选过多主要与活动强度还是传播结构/事件连接有关。暂不新增RMS阈值，不改变A0、约2秒径向测量或现有候选。

```bash
python experiments/prepare_blind_wave_review.py --source outputs/cohort_review --output outputs/blind_review --image-scale 0.5
```

需要时传`--opencv-bin`。`--image-scale`必须与源追踪缓存一致，只用于将图层坐标还原到原视频。工具核对原生帧数和时间轴，逐字节复制原视频并核对SHA256；不裁剪、补帧、重编码或重追踪。打开输出目录的`index.html`，保留整个文件夹结构。网页、标签和患者文件仅存本地，不能提交到仓库。

## 人工操作

1. 先看原视频，默认显示双壁及周围组织，必要时看全景/全片。可选白色点对仅提示候选空间位置，不提示方向。
2. 四选一：明确传播、明确局部活动、未见可信活动、不确定；未复核保留默认值。
3. 若同病例多个候选来自同一次活动，可填写相同活动组名；人工起止时间和备注均可留空。
4. 导出JSON保存结果；浏览器本机暂存只为方便继续复核。允许分批完成，不强迫给看不清的候选定性。

候选采用预先固定种子随机排序，病例用别名。页面不加载机器方向、热图、RMS、拟合/QC、临床记录或私有对应表。只显示现有候选的位置与时间，因此属于**隐藏机器判定的候选辅助复核**，并非完全独立盲评。原视频可能带有扫描仪原始标识，不承诺影像匿名化。

`review_key_private.json`仅用于之后把导出标签映射回原始病例、壁和候选；不要修改，也不要公开。`bundle_id`标记本次候选集合，后续必须按集合及token匹配，不能按行号拼接。标签不会自动改成`reviewed=True`或更新正式事件/频率。

## 比较范围和解释

- 本包收录现有C2F/F2C方向候选，不包含所有complex或未检出时段。因此不能据此估计整片敏感度或证明阴性时段无活动。
- “未见可信活动”是可见性观察，不能自动认作噪声；不确定不能归为阴性。
- 后续按人工类别比较既有RMS、时长、范围、局部到达逆序、相位及配对歧义，保留逐候选结果并按病例展示，不将同患者的候选当成独立患者样本。
- RMS与同段其他时刻的比值不是噪声SNR；局部逆序也可能出现在已知传播对照中。这两者均不直接删除候选。
- 同次活动组帮助识别重复，但尚不能自动合并成正式波次数；需要核对相位及前后壁身份。
- 已用于开发的病例只提供开发验证；这一轮不读取妊娠结局，也不调患者专属阈值。

幅度逐渐降低的已知传播对照是后续筛选规则的灵敏度检查；应固定噪声、位置、时间和检测参数，只降低真实信号，不能连噪声一起缩小。人工标签未完成前不据此挑选强度门槛。
