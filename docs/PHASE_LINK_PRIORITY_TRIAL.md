# 完整相位连接优先级：单项配对实验

此候选只用于沙盒配对测试，不进入正式CLI，不替换A0或默认波候选实现，不新增正式患者特征。公开仓库只保存通用代码和人工构造测试；患者输出留本地。

## 只改连接顺序

原相邻连接按峰值时间差从小到大选择，新的实验顺序联合使用：

1. 原生峰值对齐后的完整同号相位模板余弦相似度；不只比较共同覆盖的短片段。
2. 两段相位的持续时间接近程度，使用较短/较长之比；加一个原生时间间隔处理最短离散相位。
3. 新连接的到达斜率与此前路径斜率的一致程度。
4. 原有峰值延迟相对于相位时长的接近程度。

四项等权几何组合排序，没有据真实病例选择权重，不设置接受/拒绝分数。分数不是概率，时长相似不是已验证的生理必要条件。它只能改变有竞争时的优先选择，不能决定“唯一可选连接是否成立”。

相位模板仅在比较向量中将自身相位之外设零，以衡量未匹配的尾部；没有给缺失的组织运动补零，没有时间拉伸或重新搜索最佳延迟。幅值归一化使排序不直接偏向更强活动，绝对噪声参照仍沿用原实现。

## 固定部分

A0、原始径向A、约2秒测量、有效段、滤波频带、原噪声参照、同号/重叠/最大延迟的候选资格、三位置支持、相反相位配对、方向分类、ER及正式复核门控全部保持原样。未成足够空间路径的相位另记为短路径诊断，不从原局部信号中删除。

`experiments/phase_link_priority.py`在单次顺序调用的上下文内替换`_ridges`，退出后恢复原函数；它不是并行运行或生产调用的接口。没有修改`uterine_wave/radial_events.py`。

## 复算

```bash
python experiments/test_phase_link_priority_cohort.py --review-root outputs/cohort_review --controls-root outputs/frozen_controls --noise-reference outputs/noise_reference.json --prior-controls outputs/prior_control_audit.json --output outputs/phase_link_priority_trial
```

对预先选择的全部病例使用同一规则；复用原三纹理C2F、F2C、rigid、local_once缓存及留一纹理噪声参照，不重跑追踪、不扫描参数、不读结局。

运行时首先逐事件复现保存的基准，并断言新旧滤波数组逐值相同。记录每例候选、顺序提示、连接改变、基准连接中有无竞争的比例、已知方向恢复及负对照的方向候选。最后核对原文件哈希未变。正式次数和真实准确率仍为空。

人工构造检查覆盖正反向传播、幅度减半、完整相位与局部重叠的区别、空间/时间缺失及上下文退出恢复。它们只验证此连接实验，不能代替真实弱传播的成像验证。

## 采用原则

候选数量减少本身不算改善。应同时检查已知传播、用户已确认活动、局部/刚体对照及原生支持。只改变连接顺序若未改善额外候选，继续保持默认实现；本实验不授权再加一个分数阈值删除弱、单相或短范围活动。
