# 整体活动强度筛选：固定一轮测试

## 结果与决定

2026-11-19，复用87组既有条件和12例已标注的开发病例。**本候选不替换当前主流程：真实病例没有减少任何提案，不能解决当前数量偏多的问题。** 本轮到此停止，不继续提高阈值或按患者扫参数；不由此推断所有强度筛选都无效。

| 输出 | 筛选前 | 明确高于匹配刚体残余的提案 |
| --- | ---: | ---: |
| 12例活动提案行数 | 214 | 214 |
| 其中方向性提案行数 | 150 | 150 |

这不是波次数或临床准确率。上述为去重后的同壁提案行数相加，尚非跨壁统一的真实事件计数。每例均未减少；已撤销的期刊错误标注试跑不参与本实验。

真实病例的“整体RMS/匹配噪声上限”最小值1.73、中位数18.66、最大值119.67。当前刚体残余参照不能区分这些真实视频中的候选；这不证明它们都是真波，也不证明它们都是强生理收缩。

## 本次固定方法

参考[Wang 2022方法2.3.1.2](https://www.frontiersin.org/journals/physiology/articles/10.3389/fphys.2022.983177/full)的显著活动筛选思想，但没有照搬其曲率归一化阈值0.6。本项目仍使用既有0.5–5 cpm的径向形变率A。

**范围澄清：本轮测试的是相对于刚体残余的强度，不是将信号归一化至0–1后按0.6筛选的相对显著性。** 用户随后指出这个差别。0.6可以作为独立对照思路，但必须先规定归一化的信号和范围，不能直接用A的原始数值与0.6比较，也不能用本轮结果否定相对显著性筛选。患者物理幅度和ER不随事件筛选作归一化替换。

1. 父候选、partial、split及global ownership不改；从每个最终提案的canonical原相位证据取样，保留来源。
2. 每个native section分别在该活动相位起止范围计算RMS，所有section等权取中位数。不是最大单点峰值，也不把周围其他活动当噪声。
3. 将完全相同的相对时间/section取样形状平移到刚体残余中，保持原始section间距、相对到达错位和每列持续时间。只有完整有效的参考窗口可用。时间边界只在参考原生帧上取最近整数，不插值。
4. 参考门槛为这些匹配窗口的中位RMS最大值。活动RMS超过该值标记above_rigid_reference，否则为not_above_rigid_reference。比值1为工程参照界限，不是临床阈值；没有另乘系数或扫描分位数。
5. 三张纹理轮流留出，测试时只用另外两张刚体纹理标定；真实病例统一用全部三张。病例测量值、临床频率和妊娠结局均不参与门槛选择。
6. 强度层只给prominence，不重新决定方向，不增加、拆分或合并事件；已有ownership结果和传播提示保留。强活动仍可能是局部/同步活动，不能只因强度过线当成传播。

## 必须区分低强度与参考不足

87组的347条活动提案中，244条明确高于参考、40条不高于参考，**63条没有匹配参考**。部分纹理原生section数量较少，无法容纳其他纹理上的全宽活动；不缩短目标支持、不复制参考、不静默改成更小区域。

参考不足状态为unscored_no_matched_reference，不能当低强度或删除。保留原始证据并单独记录，不把它们计入已确认显著活动。若错误地将全部未评分提案删除，会制造明显漏失。

## 已知活动保留情况

复用滤波独立的raw observable truth及既有一对一分配。沿用原到达定义，不把滤波峰作为新真值。

| 单波相对长度注入峰值 | 原分配 | 明确高于参考的分配 | 另因参考范围不足待定 |
| --- | ---: | ---: | ---: |
| 4% | 12/12 | 8/12 | 4/12 |
| 2% | 12/12 | 8/12 | 4/12 |
| 1% | 12/12 | 8/12 | 4/12 |

不能把表中的8/12解释为强度筛掉了4个真波；这4个在该留出折中没有匹配噪声支持。包括双波在内，原有192个可观察真值身份中180个有分配；明确高于参考的有127个。保留未评分证据后仍为180个；低强度剔除没有减少原已分配身份的section支持。该结果不证明未评分活动通过了显著性验证。

纯刚体条件本来没有提案，仍为0；信号层非传播对照的方向提案从1降至0，但图像级local_once仍可留下方向提案。强度不能代替传播真实性判断。局部/同步活动本身有已知真实形变，不应将所有此类活动一概当零活动。

## 复现和接口

```bash
python experiments/test_activity_strength_trial.py --output outputs/activity_strength_trial_20261119_v1
python -m unittest discover -s tests -p test_activity_strength.py -v
```

默认读取既有87组ownership、父候选、split、12例ownership/maps及刚体缓存；可通过显式参数指定路径。输出全部决策、逐section强度、每纹理匹配窗口数、原生支持、评分比例、真值分配及输入/代码SHA256。病例数据及输出留在忽略目录。

experiments/activity_strength.py不读取真值或结局，仅负责强度与参考匹配；runner在评分后单独调用既有真值评价。三项必要接口测试覆盖匹配窗口枚举/缺失、单section尖峰稳健性、未评分不能当低强度。A0、正式幅度、ER和事件连接器的源码哈希在运行前后不变；正式次数、频率、临床准确率仍为null。
