# 固定残余噪声的弱传播与同步活动对照

这是一组**下游径向A信号层**检查：在既有三张纹理的刚体追踪残余上叠加已知信号，评价当前候选及连接预测诊断。不生成变形视频，不重新追踪，也不证明真实低信噪比散斑可以被准确追踪。

## 固定输入

- 沿用原刚体缓存、约2秒实际测量跨度、时间/s轴、有效支持及留一纹理噪声参照。
- 以一段Gaussian径向点距变化构造已知有限区间A：`(L_after-L_before)/L_before/dt`。中心固定30秒、宽度4秒，正反传播速度固定0.04完整路径/秒。
- 点距扰动峰值固定4%、2%、1%，只改变注入伸缩，不缩放残余噪声。逐条件检查`mixed-clean == same_noise`的浮点一致性。
- 另有五个中心位置同时伸缩、全部位置同时伸缩及仅刚体残余三种对照。同步伸缩是真实活动对照，只针对“有无传播”的误判，不把其活动幅度当噪声删除。

所有数值是预先固定的机制测试输入，不是临床阈值，也不按某个患者调整。三纹理×（两方向×三幅度＋三对照）共27个信号组合，两壁使用相同注入信号和各自的固定残余。

## 评价

保留原检测器的全部候选，计算已知方向是否出现、与注入结构相符的到达误差和空间支持，以及已有预测诊断。已知全路径输入先匹配最大空间支持，再比较到达误差，避免只挑一个误差很小的短片段声称恢复完整波；此匹配原则只用于该固定全路径测试，不排除真实短路径活动。

候选数量不等于注入事件数。一次已知传播仍可能产生多个相位片段或滤波旁瓣候选，必须另行报告，不将“方向存在”包装成计数正确。仅出现正确方向也不自动证明所有位置均恢复。

`phase_prediction_evidence`只是记录预测形状和到达误差，不施加新门槛。特别检查同步活动的额外候选是否也有高形状相似度；若有，就不能把高相似度单独当成有波。

## 运行

```bash
python experiments/test_weak_wave_signals.py --controls-root outputs/frozen_controls --noise-reference outputs/noise_reference.json --prior-controls outputs/prior_control_audit.json --output outputs/weak_wave_signal_check
```

程序核对源缓存哈希和噪声一致性，保存逐组合全部候选及逐壁匹配。没有修改A0、真实患者候选、幅度、ER或正式事件定义。公开代码只提供实验入口，真实纹理残余及结果保持本地。
