# 完整视频人工参考：首轮小批复核

`experiments/prepare_whole_video_reference.py`整理现有12例原视频及ownership提案，
不运行检测、追踪、特征计算或准确率估计。`whole_video_reference.html`为本地标注页。

首轮只看3段完整视频：发生新增拆分的一例、此前看到明确传播的一例、此前存在整体运动
干扰的一例；约3分19秒。其余9例可选。这是有目的选取的开发病例，不是独立临床验证，
不能据此直接报告人群准确率。既有人工观察不自动填入新参考标签。

## 复核流程

1. 默认全景、1倍速，先完整观看；原生视频不补帧、不重新编码。
2. 人工添加明确传播、局部活动或不确定活动，记大致时刻即可；粗起止边界可留空。
3. 方向使用C2F/F2C/复杂/不确定，C/F端从既有标注和有效追踪点显示，仅作方向参考。
4. 同一次活动若在两壁都出现只记一条，可选择双壁/整体；不分别数成两次。
5. 看完整段后明确选择“活动已记录”“未见明确传播”或“看不清”。
   未复核、看不清、不确定活动都不自动变成零次。
6. 再按需展开程序对照。页面会深拷贝保存展开前的人工记录；后续修改标记为对照后编辑。
7. 导出JSON（完整记录与独立快照）给分析者；CSV为可选备份。支持导入同批JSON继续填写。

机器结果虽随本地页面载入，但默认不显示；这不是严格统计盲法。标注仍可能受到之前
开发讨论影响，应如实记录。此页只提供原始人工参考，不自动作事件匹配或真假判定。
后续需逐时段对应人工与程序，并保留方向不确定、局部活动和不可判读的区别。

## 数据与接口

```bash
python experiments/prepare_whole_video_reference.py \
  --video-review outputs/blind_wave_review \
  --ownership outputs/global_ownership_real \
  --output outputs/whole_video_reference
```

输出`index.html`、数据脚本、私有token来源键、协议和简明说明。视频沿用原文件的相对
链接，打包/移动时须保留目录关系。逐个核对视频哈希与冻结复核清单，原时长和fps沿用
已验证元数据。不读取妊娠结局，不上传患者视频、图像、标签或任何衍生结果。

JSON导出包括：bundle/算法版本、case token、完整复核状态、人工event ID、粗时刻、
可选边界、活动类型、方向、壁、备注、程序对照展开时刻及独立参考快照。整段状态与
活动行同时保留；无活动行不能单独解释为无波。页面保存人工草稿记录数，但不输出
正式患者频率或临床准确率。
