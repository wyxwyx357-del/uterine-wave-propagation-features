# 保留位置方向复核与身份优先试验

本轮只测试事件层，不修改A0、径向形变、0.6显著筛选、幅度、ER或正式患者结果。目标是修正两个已确认的接口问题：显著筛选缩小空间范围后仍继承原方向，以及前后壁先按方向分流可能把同一次方向冲突活动计为两次。

## 候选逻辑

1. 只读取现有0.6显著候选，不产生新候选。
2. 在实际保留的native sections上重新拟合arrival证据。原方向与保留段不一致、或保留段无法给出方向时，记录为方向待定；不自动翻转方向。
3. 跨壁先比较时间、相邻空间位置和相位证据，再综合方向。两壁方向冲突时只保留一个待定活动身份。
4. 身份匹配沿用已有约2秒容差和至少3个相邻位置。允许一壁多出局部相位，但一对多竞争不强行合并。
5. 方向不单调、拟合误差等连续证据全部保留，不新增单项一票否决阈值。

## 结果

- 5项最小接口检查通过：保留段方向冲突、跨壁相反方向、额外局部相位、时间分离和一对多竞争。
- 3张纹理、C2F/F2C、单强波/20秒双强波共12组均保留正确身份与方向，12/12通过。
- 扩展到已有66组带真值且经过0.6后仍有支持的条件：80个已保留真值身份中78个各表示一次；没有反方向判定，没有把不同真值合并。`texture0_double_F2C_0.04_gap10`的两个真值仍各被重复表示两次，说明10秒相邻双事件的同壁归属问题尚未解决。
- 15组rigid、local-once及同步非传播对照没有保留方向行；23条活动证据进入方向待定。该结果只说明没有新增方向性假候选，不说明局部活动不存在。
- 12例真实视频中，C2F仍为13条；F2C由6条降为3条；原有3条非单向/未定活动加上3条方向复核未通过，共6条待定。353由`C2F=1/F2C=3`变为`C2F=1/F2C=1/待定=3`，1101由`2/1`变为`2/0/待定=1`。
- 真实显著候选仍没有形成可唯一确认的跨壁身份配对，因此本轮没有用较宽松匹配直接降低真实病例次数。

## 判断

保留位置重算方向值得进入正式候选输出，因为它修正了真实病例中的方向继承错误，同时保住12/12必要强波对照。身份优先的总体顺序也成立，但10秒双事件仍有重复表示，不能据此冻结正式次数或频率。当前正式患者表不覆盖；`event_count`与`event_frequency_cpm`继续为空。
