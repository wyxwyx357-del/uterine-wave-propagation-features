# 保留位置方向复核与身份优先试验

本轮只修改事件汇总层，不修改A0、径向形变、0.6显著筛选、幅度或ER。目标是修正两个已确认的接口问题：显著筛选缩小空间范围后仍继承原方向，以及前后壁先按方向分流可能把同一次方向冲突活动计为两次。

## 候选逻辑

1. 只读取现有0.6显著候选，不产生新候选。
2. 对实际保留的每个连续native-section block分别拟合arrival证据，禁止跨越没有显著支持的空间缺口。任一block与原方向冲突、或所有block均无法定向时，记录为方向待定；不自动翻转方向。
3. 跨壁先比较时间、相邻空间位置和相位证据，再综合方向。两壁方向冲突时只保留一个待定活动身份。
4. 身份匹配沿用已有约2秒容差和至少3个相邻位置。允许一壁多出局部相位，但一对多竞争不强行合并。
5. 方向不单调、拟合误差等连续证据全部保留，不新增单项一票否决阈值。

## 结果

- 6项最小接口检查通过：保留段方向冲突、不连续block隔离、跨壁相反方向、额外局部相位、时间分离和一对多竞争。
- 3张纹理、C2F/F2C、单强波/20秒双强波共12组均保留正确身份与方向，12/12通过。
- 扩展到已有66组带真值且经过0.6后仍有支持的条件：80个已保留真值身份中78个各表示一次；没有反方向判定，没有把不同真值合并。`texture0_double_F2C_0.04_gap10`的两个真值仍各被表示两次。node级审查确认这不是同壁重复：同一真值分别由前后壁的互补纵向区段表示，而当前身份匹配要求共享section，所以没有合并。相邻两波又存在错误交叉配对的可能，故本轮不新增互补区段合并规则。
- 15组rigid、local-once及同步非传播对照没有保留方向行；23条活动证据进入方向待定。该结果只说明没有新增方向性假候选，不说明局部活动不存在。
- 12例真实视频中，C2F由13条降为12条，F2C由6条降为3条，共7条方向待定。353由`C2F=1/F2C=3`变为`C2F=1/F2C=1/待定=3`，1101由`2/1`变为`2/0/待定=1`；527的一条跨不连续显著区块拟合的C2F转为待定。
- 真实显著候选仍没有形成可唯一确认的跨壁身份配对，因此本轮没有用较宽松匹配直接降低真实病例次数。

## 判断

逐连续区块重算方向与“身份优先、方向其次”已经接入患者汇总，并保住12/12必要强波对照。10秒相邻双事件仍有跨壁互补区段重复表示，0.6也仍会漏掉弱第二波，因此程序可以输出当前定义下的方向波数，但不能据此宣称生理真实频率已完成验证。`event_count`与`event_frequency_cpm`接口继续为空。
