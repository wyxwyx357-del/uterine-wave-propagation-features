# ROI外多点共同运动核对

本实验只核对周围组织的共同运动和既有整体校正，不更新A0目标轨迹、径向形变、波候选或患者正式特征。

```bash
python experiments/audit_external_motion.py --source outputs/cohort_review --review-id case_example --start-s 10 --end-s 26 --preview-s 17 --check-end-s 20 --output outputs/external_motion
```

Windows CUDA OpenCV需要时传`--opencv-bin`。该入口使用本项目这批缓存固定的0.5图像缩放；不是任意尺度轨迹的通用导入接口。输出患者视频、图像和点位只留本地。

## 放点和多数一致

- 在分析区径向点凸包之外28–135 analysis px的环带选择参考点；有效超声组织区取灰度阈值后的最大连通分量并向内侵蚀，避开黑边和大部分扫描仪标识。参考位置需要看输出视频核对，不能由此宣称解剖上无收缩。
- 环带按角度分成8区，每区最多8个Shi–Tomasi角点，避免全部集中在一处。分区、距离和数量为本轮工程设置，不是文献生理门槛，不逐患者调参。
- 沿用当前21×21 LK、pyramid=3、30 iterations及原NCC/FB。参考点失追后不补邻点、不重新接段；支持点数量逐帧输出。
- 刚体拟合仅允许平移、旋转，禁止缩放和剪切。通过固定种子的两点模型寻找最多支持点，再用一致点拟合。几何一致容差固定1 analysis px，是实验模型设置，不是波强度/有效性规则。
- 同时记录有效点数、一致点比例及覆盖的区域数。点数占多数不等于组织来源独立，也不等于已测得真实探头姿态；记录多数不成立，不强行把少数模型当作全局真值。

## 原生帧与约2秒检查分开

原生帧间位移很小，同一个宽松的像素容差可能让几乎所有点都通过。因此原生帧多数通过率不能代表几秒尺度仍是刚体。实验另外以最接近2秒的原生帧跨度，在全段连续有效的同一批外部点上检验刚体一致性，与径向测量的实际时间跨度一致。

可选`--check-end-s`另保存从`--preview-s`到指定时间的点位左右运动数、位移分布和各区位移中位数。正负号只是描述方向，没有据此建立探头运动诊断阈值。

## 输出解释

- `external_motion.npz`：原生点轨迹、QC支持、原生帧及约2秒的刚体一致点、区域编号、变换和时间轴。
- `comparison_1x.mp4`：左侧原视频与外部点，右侧逐帧累积的刚体稳定显示。保留所选时段每一原生帧及1倍速。绿色仅表示约2秒模型一致；橙色是其他QC支持点；最初不足2秒为蓝色。
- 右侧是诊断预览，可能累积漂移；当约2秒无多数支持时明确标为未确认。稳定后“看着不动”不证明校正正确，也不表示波已删除或修复。
- `motion_diagnostics.png`：外部点与既有校正预测在同一ROI中心的运动、支持点数、拟合残余及原有A0径向RMS。既有变换是图像→参考，比较前转换为source→target，不能直接将矩阵平移项当作ROI中心位移。
- 残余同时列出全部相同QC点和仅一致点的结果。外部模型在这些点上拟合，残余不是独立定位真值，不能因其较小就宣称优于现有校正。

整体平移和旋转保持径向点距不变。该实验不能通过“减掉共同位移”消除点间不一致定位、真实组织形变、压迫或出平面变化。出现共同运动后，需继续查其与局部异常的时间/空间关系，不能把有整体移动的时段全部判成假波。

原始目标轨迹与候选文件不覆盖；本入口没有事件删除、频率汇总或妊娠结局输入。先在用户指出的晃动段及已有阳性活动对照中采用相同设置，结果仅作机制核对，不声称独立验证或已经优化检测器。
