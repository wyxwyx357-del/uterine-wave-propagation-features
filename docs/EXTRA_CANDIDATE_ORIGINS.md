# 已知输入中的额外候选来源追溯

此入口只分析固定噪声信号层对照中的额外方向结构，不更改A0、滤波或事件规则。利用已知注入波形定位来源，因此结果不能直接作为真实患者的删除判据。

```bash
python experiments/audit_extra_candidate_origins.py --signal-root outputs/weak_wave_signal_check --controls-root outputs/frozen_controls --review-root outputs/cohort_review --output outputs/extra_candidate_origins
```

## 三条可检查的实现路径

1. **频带截断与峰值门槛。** `amplitude.band_limited_signal()`将频带外FFT系数置零后重建；孤立已知脉冲的重建波形可出现前后额外振荡。程序逐点记录原注入信号、其滤波分量、残余滤波分量及二者之和，核对线性关系。`radial_events._lobes()`的峰值门槛来自既有带内SD噪声参照，这不构成最终事件级误报率校准。
2. **边界截断整段删除。** `_lobes()`当前丢弃接触连续块开始或结束的整个同号相位；即使峰值位于记录内部，它也会消失。周围位置的同号路径可能因此分成空间片段。
3. **整条相位路径的一对一配对。** `_pair_phases()`按整条ridge分配相反相位，禁止任何ridge ID复用。一个完整相位与多个空间不重叠的相反阶段片段，可能只能选择其中一段，其余作为单相候选保留。防止重复使用相位与识别独立活动的归属是两个层面，当前实现尚未解决后者。

这不是建议去掉频带、提高幅度门槛、跨失追补点或将所有单相活动删除。频带仍用于原幅度和ER；单相和短路径活动可能有真实支持，应保留证据和不确定性。

## 受控因果干预

对已知注入中出现的一个明确相位缺口，仅恢复一个确实存在、峰在记录内部但尾部接触边界的节点，保持原波形、噪声、门槛和其他步骤不变。仍记录该相位的边界不完整状态。

这个操作利用了已知注入真值选择恢复位置，是用于确认删除路径是否造成片段拆分的定向干预，**不是可部署的恢复算法**。不在真实患者中自动插入相位节点，不输出修改后的正式事件数。

## 真实病例的结构核对

可选`--review-root`在预选全部病例中查找共享相反相位、空间支持不重叠的候选关系，并记录阶段先后和方向是否一致。这些只是潜在归属关系；同一相位也可能关联不同活动，不能把关系数当成重复波数量或直接合并。

程序核对源文件哈希，保存逐条分解、定向干预及候选关系。公开仓库保存通用代码和说明，病例缓存、结果及患者材料仅留本地。该分析不报告临床准确率提升。
