# 验证记录：本轮代码整理

日期：2026-11-16。原冻结工程和历史结果未修改。本仓库提取当前布点、分段追踪及 A/B 测量流程，补充可运行接口和公共软件验证。

## 整理前后配对

在同一份人工几何/纹理与同一组种子上比较：

- 布点、显式索引及实际弧长坐标：逐值一致。
- 五种条件的完整 501 帧解析映射轨迹：A/B 结果绝对容差 1e-13 内一致，ER 绝对容差 1e-12 内一致。
- 同五种条件各取前 25 帧，原 CUDA 跟踪链与独立包并行复算：位置、校正位置、NCC、FB 在绝对容差 1e-7 内一致；有效、步骤、段号、重定位、恢复尝试及状态字符串逐值一致。

这项检查说明提取模块没有改变已比较样本的数值行为，不是新增人体准确性证据。未拿完整患者原片重跑充当本次整理的必要条件。

## 软件检查

14 项数值/接口测试加 2 项 CUDA/视频检查，共 16 项：

- 解剖排序反转不变、刚体几何等变、径向基准长度、实际弧长。
- 静止零形变、已知伸长率、曲率刚体不变和缩放关系。
- 失追、段变化、校正阶段及区间中间 NaN 的有效支持。
- 正反行波、站波/双向平衡和静止方向谱；不把 ER 输出视为事件检测。
- 标注→布点→轨迹→特征的文件接口，非均匀时间处理。
- CUDA 静止/整体平移冒烟检查；合成视频解码帧数及 3 倍速真实时间尺度。

无 CUDA 环境运行 14 项、明确跳过 2 项；本机 CUDA 环境运行全部 16 项。GPU 冒烟检查只验证软件链路，不设新的临床准确率门槛。

已在具备 wheel/setuptools 的本地环境成功构建 Python wheel；构建依赖在 pyproject.toml 中显式声明。

## 可公开复现的完整图像对照

`python -m uterine_wave controls --output outputs/synthetic_controls.json`

人工纹理，五种条件，每种 501 帧、0.12 s，完整 60 s。已跑通，结果见 [synthetic_controls.json](synthetic_controls.json)。静止位置误差为 0；其余条件有效比例约 99.95%–100%；正反向 A/B 的 ER 符号符合各自参考。部分种子失配保留在有效掩码中，没有删除原始缺失以包装全通过。

该控制使用解析给定的准确背景姿态，因此不验证真实背景估计器。几何取自同一初始化结构；变形为静态纹理的图像重采样，不含原片自发运动或散射体重新成像。人工纹理结果不能替代真实数据验证。

三张真实视频首帧各做五种条件，共 15 组。只保留不含身份信息的 [聚合结果](development_controls_summary.json)。

| 指标 | A 径向 | B 窄带曲率 |
|---|---:|---:|
| 正反传播方向符号符合参考 | 12/12 | 18/18 |
| 波动 RMS 比例的平均绝对偏差 | 3.25% | 9.59% |

这里的 12/18 是壁/曲线级比较，不是独立患者数。ER 的刚体残余说明方向不平衡不一定代表生理传播。0.1 只用于回顾诊断数值，不作为本代码事件判定门槛。A 保留为主候选，B 为补充候选；不能把这些结果说成全部临床特征已验证。
