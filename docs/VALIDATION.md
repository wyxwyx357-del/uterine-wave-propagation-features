## 软件检查

14 项数值/接口测试加 2 项 CUDA/视频检查，共 16 项：

- 解剖排序反转不变、刚体几何等变、径向基准长度、实际弧长。
- 静止零形变、已知伸长率、曲率刚体不变和缩放关系。
- 失追、段变化、校正阶段及区间中间 NaN 的有效支持。
- 正反行波、站波/双向平衡和静止方向谱；不把 ER 输出视为事件检测。
- 标注→布点→轨迹→特征的文件接口，非均匀时间处理。
- CUDA 静止/整体平移冒烟检查；合成视频解码帧数及 3 倍速真实时间尺度。

无 CUDA 环境运行 14 项、明确跳过 2 项；本机 CUDA 环境运行全部 16 项。GPU 冒烟检查只验证软件链路，不设新的临床准确率门槛。

已在具备 wheel/setuptools 的本地环境成功构建 Python wheel；构建依赖在 pyproject.toml 中显式声明。
