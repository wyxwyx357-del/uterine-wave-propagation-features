# 暂时隐藏一个位置的相位连接检查

目的：检查现有传播候选在空间上是否能够互相预测，减少“先按自己的峰对齐，再用高相似度证明传播”的自我印证。本工具不改变候选、A0或任何正式患者特征，不输出新的接受/拒绝规则。

## 方法

对一个既有候选的每个正/负相位，依次暂时隐藏一个空间位置：

1. 仅用其他位置的原生峰值时间，拟合到达时间与原始完整路径坐标s的直线。
2. 预测被隐藏位置的到达时间，保留预测误差；端点为外推，内部为插值，分别记录。
3. 将其他位置的完整相位模板归一化到单位能量，放到预测到达时间，平均形成形状预测。
4. 与被隐藏位置的实际完整相位比较，给出余弦相似度；另保留使用其真实峰对齐后的相似度作为对照。

预测过程中不使用被隐藏位置的到达峰，不搜索最佳延迟、不拉伸时间、不插值帧。归一化减少对强活动的直接偏好；原有候选绝对噪声参照不变。

相位以原连续有效段恢复，比较模板在相位之外为零，只定义比较向量，不给缺失运动补零。预测模板被限制在被隐藏位置的原连续有效段内；截断支持比例和实际使用的模板数量均输出。预测到达时间在有效段之外时，形状相似度为空，不能把它默认为零相似度或假波。

## 解释边界

- 这是同一次活动连接的**内部一致性诊断**。原候选的选择已经使用所有位置，不能称为独立临床验证、完全留出验证或分类准确率。
- 常速直线近似与当前事件速度拟合一致；真实传播加速、形状变化及追踪误差都可能降低预测，因此不单指标否决。
- 时间误差同时给秒数和相对于该相位实际到达时间范围的比值；极短空间/到达范围对定位误差更敏感，不能只看绝对秒数。
- 归一化误差、形状相似度都不是概率。平滑的带内噪声仍可能可预测，高相似度也不能单独证明有波。
- 双相候选分别评价每个相位，再等权汇总；相位身份和事件次数仍保持原定义及复核门控。

## 运行

```bash
python experiments/audit_phase_prediction.py --review-root outputs/cohort_review --controls-root outputs/frozen_controls --noise-reference outputs/noise_reference.json --prior-controls outputs/prior_control_audit.json --output outputs/phase_prediction_audit
```

全部预先选择病例采用同一方法，复用三纹理×C2F/F2C/rigid/local_once对照和原留一纹理噪声参照，不重追踪、不扫参数、不读取结局。核对源缓存哈希。输出逐预测、逐相位、逐候选及逐病例结果，正式次数和新阈值保持为空。

公开代码仅用于复算；患者图像、人工标签、结果与病例对应表仅保存在本地。人工构造测试验证可预测的正向传播、幅度降低、错误到达顺序及有限有效段，不代替真实超声检出验证。
