# 活动相位角色与身份关系：沙盒可行性试验

本轮用户要求测试定义审查的下一步。仅复用既有87组保存结果建立相位身份关系，不重新检测、不修改正式计数，不调整0.6、arrival、phase-fit、跨壁匹配或coverage阈值。此试验不是完整wavefront检测器，也不是已修复误计的算法对照。

## 方法

每个已有活动保留显著区块、原始parent/child来源及完整相位上下文。用已有measurement span+dt容差和3相邻位置参照，检查两个活动是否有同极性相位峰对应。同壁要求epoch相同；跨壁仅分别要求有效epoch。完整上下文用于发现可能重复的相位，不能提升为显著传播支持。共享一个相位仅记录待定关系，不自动推断同一完整活动。方向不参与。

## 结果

87组中73组有至少一条相位对应关系。这包含正确的跨壁同波表示，不是73组错误，也不是73组修复成功。

### local_once

保留的四条显著活动中，现有计数器将前壁正单相、后壁负单相各计一次。沙盒在原始上下文找到前后壁正相位在10–12三个位置对应；其余单相没有足够的相同相位对应。没有直接证据把前正与后负绑定为同一完整活动周期。不能仅因为这个fixture真值已知同步，就把真实视频的类似斜向单相证据一律改为0。

因此当前计数2未变，不能报告local_once已归零。

### 10秒双波

六条活动与审查一致：四条+→−child（两个truth各有两壁表示），两条−→+base。发现三组可能的共享相位：

| 活动A | 活动B | 对应相位 | 连续支持 |
|---|---|---|---|
| 前base002 | 前child006 |负相位|13–18|
| 前base002 | 后child009 |负相位|2–4，另有6|
| 前child005 | 后base004 |正相位|12–14|

这使“额外base与已有活动并非完全无关”得到实际证据；但每组都只有一种极性，尚不能确定是同一波的恢复阶段，还是相邻两波共享/混配了相位。一个base还与多个表示有关系，必须保留ownership竞争，不能传递合并整个连通分量。

因此当前计数6未变，不能报告双波已变2。已知truth只用于上轮定位，本轮关系图没有读取truth标签或据其选择归属。

## 验收与结论

| 目标 | 本轮结果 |
|---|---|
| 发现相位重复/角色关系 | 找到具体节点证据 |
| local_once从2变0 | 未实现 |
| 双波从6变2 | 未实现 |
| 引入50%或其他新阈值 | 无 |
| 修改正式计数 | 无 |

下一步缺的是完整局部活动的相位周期身份，而非再增加一条合并阈值。本轮只证明已有候选间存在需要解释的相位复用，不能证明无参数地唯一恢复wavefront。若没有独立周期证据，正确做法仍是记录可辨识范围和未定归属，不能依靠已知truth强行凑0或2。
