# 当前波特征定义与计算入口

目标是测量与妊娠研究有关的真实局部伸缩和传播；定义与文献相近，算法不要求逐项复现。当前版本`radial_wave_features_v2`。A0追踪冻结，主输入为`compute_spacetime`的约2 s径向图，实际跨度逐样本保存。

## 幅度

`epsilon(t)=[L(t)-L(t-h)]/L(t-h)`，`A=epsilon/dt`。主幅度为各点对epsilon的0.5–5次/分频带SD，再取固定区域内点对的算术均值。名称：**径向伸缩活动幅度**；无量纲，乘100显示为%。无滤波SD保留QC。

Sammali 2019第137–138页同样基于相邻测量时刻相对点距变化与频带SD；本项目不同的是同壁径向点对、测量跨度、采样密度与区域汇总。原研究正常周期频带约0.48–3.96次/分，IVF研究常用0.5–5次/分。不能把不同运动方向或跨度的数值直接比较。

区间差分同时受伸缩大小与运动快慢影响，因此该幅度不是完整单次收缩的总缩短百分比，也不代表收缩力或压力。每个连续有效段独立滤波，禁止拼接后滤波。一个点对多段按样本数合并段内方差再开方，不引入重定位前后的基线跳变；随后空间等权均值。保留逐段时长、频率分辨率和逐点对支持。至少容纳一个带内FFT格点是数值条件，不是生理证据。

## 方向、模式速度及协调性

ER为`(E_C2F-E_F2C)/(E_C2F+E_F2C)`。正值C2F，负值F2C；接近零只表示方向能量平衡。绝对方向能量、方向RMS及刚体参照用于解释活动支持，属于QC。

`modes.analyze_modes`继续提供20 s模式窗及前后壁ER的零时延Pearson CC、MSE。这些是有文献依据的协调性代理，不要求先完成逐波匹配。小MSE也可来自两壁都弱，必须结合活动支持。固定区域必须实际覆盖两壁被比较位置；相同归一化s不保证同一物理横截面。

模式速度仍为`-ft/fs`，默认裸谱速度保留候选身份。`--refine-mode-speed`可显式复用已有连续双向时空拟合，保留原谱峰、拟合残差、边界和收敛诊断。20 s窗口的低频信息不足不会因连续优化而消失，不把未解决的模式速度自动汇总为患者真实波速。

## 已复核事件及频率

一次事件是在连续相邻空间位置依次出现的同一径向伸缩结构；允许部分路径，不要求从宫颈贯穿到宫底。红蓝双相属于同一次活动的不同阶段，不分别计数。一个事件ID标记一个独立活动；两壁确认属于同一活动时共享ID。明确反射后形成的反向活动分为新ID；同时双向/非单调活动保留complex，不强行给单一速度。这是本项目计数约定，需在人工对照时保持一致。

正式事件接口**测量复核过的事件**；下述自动模块仅提供待复核候选。输入需要起止时间、至少三个相邻section及同一结构的到达时间；三点是拟合数值条件，不是文献生理门槛。用到达时间对完整归一化s线性拟合，斜率单位s/路径，速度为倒数；报告拟合R²/RMSE。到达差小于一个原生采样间隔视为未解析传播；非单调为complex。事件窗口必须完整有效，不跨失追/重定位边界。

事件内epsilon的无滤波逐点对SD均值作为明确命名的事件伸缩活动幅度，**不在几秒事件窗强行计算0.5次/分幅度**。双壁事件按已复核共享ID配对，报告同一采样位置的后壁减前壁到达差和方向一致性。患者速度先合并同一事件的双壁测量，再分别对各方向事件取中位数。

频率=唯一事件数/有效观察分钟。观察使用显式固定解剖区域，分母为指定复核时段内至少一壁该区域连续有效的时间并集；重复/重叠时段不重复累加。缺失不记无波。只有声明完整复核、无未解决事件且存在有效时长时输出正式次数/频率。未输入复核时为null；完整复核且无事件时才为0。

## 自动径向传播候选

`radial_events.py`在当前A上寻找可供复核的伸缩结构，不改追踪、epsilon、主幅度、ER或正式事件定义。每列的连续有效段独立做现有0.5–5 cpm频带处理，保留正负相位；相邻空间位置同相位关联后，将相邻的相反阶段配对。两相之间的过零时刻作为同一相位转换的到达标记，输出位置、到达序列、拟合与候选方向/速度。它是滤波后有限区间A的到达标记，不是瞬时组织伸缩极值；不直接计数全部零交叉，也不是R2单点频率。

2026-11-18更新：取消最小15%路径范围和4点排除条件。至少3个相邻位置仍是拟合的数值条件，短范围本身不否定传播。每个相位结构至多参与一个选中结构；没有配对的相位也保留为`single_phase`候选，不能仅因缺少另一相就删掉证据。单相可能属于同一次活动的不同阶段，因此候选数量不能直接作为波次数。

配对现在最大化“共同位置数×传播一致性”，不再奖励配对数量或某个先行极性。传播一致性是到达拟合R²、空间位置对的时间顺序一致比例、拟合时间跨度相对残差的连续工程评分；相位转换和两相峰值均参与，再结合方向一致程度。它用于候选关联，不是临床概率或显著性检验。评分及公式见`_arrival_evidence`与`_measure_pair`，没有依患者方向标签优化权重。保留所有未选配对的完整测量`alternative_phase_pairs`，而非仅留下最优匹配。

`evidence_kind`区分paired_phase/single_phase；对应到达标记`arrival_marker`分别是相位转换过零和单相峰值，不能把这两种标记直接混用为同一事件到达。每项保留`quality_flags`、到达R²/RMSE、顺序一致比例、空间范围、相位配对歧义。裁剪边界的未完整相位仍可能漏检；周期连续、分支、反射等事件边界需复核。

输入`noise_floor`为A的绝对阈值，单位s^-1，需要记录噪声参照；不按每个视频的离群z值定义运动。当前开发验证使用其他刚体纹理中各点对频带SD的P95乘3，留一纹理评估；这不是临床阈值或保证误报概率的统计界限。短段的FFT分辨率、周期边界及去相关也会影响候选，不能因越过阈值就认定生理活动。

R²=0.5仅为保留的工程提示参考，不再单独否决候选；非单调也先报告提示。近同时仍按max(原生采样间隔,0.5 s)标synchronous；同时存在非单调与弱拟合或相位方向冲突时标complex，其余提供待核对C2F/F2C方向和速度。这些分类是复核提示，不是确认有波。`RadialWaveConfig`删除旧`min_space_points`/`min_path_span`字段，保留`min_fit_r2`和`synchronous_tolerance_s`；CLI参数不变。两相拟合使用相同共同空间范围，速度保持完整路径/秒，不按局部范围重新缩放。

所有候选`reviewed=false`，正式`event_count`/`event_frequency_cpm`保持null；两壁候选数不相加。人工应检查原视频及径向图的同一活动，修订位置/边界/到达并统一双壁event_id，再接入原`--review`接口。**双相只是本轮可测试的候选表示，不要求所有生理波都必须呈双相，也尚未验证自动计数准确率。**

```bash
python -m uterine_wave wave-candidates --maps outputs/maps_2s.npz --noise-floor 0.001 --s-range 0.2 0.8 --output outputs/candidates.json
```

0.001仅为命令格式示例，应由所用噪声参照替换。JSON包含逐壁候选和歧义，伴随NPZ保留原生坐标、过滤信号与有效mask；未选区域和缺失均为NaN，不填补、不跨断段配对。

## 使用

`--time-range`表示原始采集时段：要求每个保留样本的`interval_start_s >= START`且`interval_end_s <= END`，不是按中心时刻裁剪。若旧缓存仅保存中心和实际dt，可由`center +/- dt/2`精确恢复端点，不插值运动。例：10–50 s的2 s测量对应中心约11–49 s。复核时段也按完整测量区间计算有效支持，不把两端没有完整支持的原始时间计入分母。

输出`analyzed_acquisition_time_range_s`说明实际使用的原始区间，`analyzed_interval_center_range_s`说明保留的中心范围；历史键`analyzed_time_range_s`仍是中心范围。`requested_acquisition_time_range_s`记录请求，不能混用这些时间含义。

主幅度要求预设区域每个section均有至少一个达到现有幅度数值条件的连续段；缺一个section，`radial_stretch_activity_amplitude`即为null。`partial_region_activity_amplitude_QC`与逐点对/逐段结果保留局部诊断，不并入主幅度。该要求不要求所有点全片持续有效，亦不改变ER和局部分析。当前约12 s仅为至少一个带内FFT格点的数值下限；统一主分析最短时长/频率分辨率仍需按研究方案预设，本次未自行新增阈值。

```bash
python -m uterine_wave summarize --maps outputs/maps_2s.npz --s-range 0.2 0.8 --time-range 10 50 --output outputs/patient_features.json
```

空间/时间范围应依据解剖与研究方案预先选定，不按波最明显或结局选择。输出记录实际采样范围、逐壁/逐点对有效支持与时长；不同区域和不同时长不能当作同定义患者直接比较。长视频可选择有效局部，不能伪装成整壁结果。

可选`--review review.json`，示例仅解释格式，不是患者真值：

```json
{
  "complete": true,
  "intervals": [[10, 50]],
  "events": [{
    "event_id": "wave_001",
    "wall": 0,
    "reviewed": true,
    "start_s": 20,
    "end_s": 35,
    "sections": [4, 5, 6],
    "arrival_time_s": [25, 27, 29]
  }]
}
```

section为NPZ内**从0开始**的列索引，不能把原图P1直接当成索引1。事件到达时间必须来自同一径向结构的复核；只有80–88秒等粗标、没有位置到达信息时，不应编造这些输入。
