# 患者级统一活动汇总与临床对照

2026-11-19用户要求重新汇总：临床记录针对患者/整个子宫，主表不能再按两壁分别计数。两壁保留为运动测量与协调性通道，患者活动清单共享一个身份空间。

## 本轮边界

保留既有A0、物理幅度、ER、CC/MSE、频带、0.6归一化和同壁ownership。只增加跨壁身份对应和患者级展示；不按临床数值选参数，不读取结局。

取每个显著候选的原生位置、相位顺序、相位峰值、arrival标记和方向。相同位置上的相位顺序、峰值时序与arrival均相符，且至少3个相邻native位置支持、两端互为唯一对应时，提议共享一个患者活动ID。时间容差沿用原measurement span＋一个native间隔，约2秒；这是工程关联容差，不是文献证明的最大双壁生理时延。

两壁是不同组织位置，不要求两壁具有相同track segment或有效run边界；但每壁自己的证据必须连续有效。仅时间靠近不足以合并。单壁候选保留；一对多竞争、相位或方向冲突保留未定，不传递合并相邻活动。不将径向形变符号直接解释为传播方向。

## 汇总结果

- 12例中，7例仅一壁有显著候选，3例两壁有候选，2例无显著候选。
- 输入22条显著壁提案，没有找到达到上述对应规则的唯一跨壁配对；因此追溯清单仍有22行。不能将这句话解释为“已证明22次独立真实波”。
- 其中1例有两组部分/冲突跨壁对应，涉及4条记录。若这些对应最终证实共享身份，该例为3个候选；若保持独立则为5个，故主表显示3–5，而不是强行取5或3。
- 其他11例当前没有被规则标为未定的跨壁对应。条件总数为20–22；这是针对已记录对应关系的条件范围，不是统计置信区间，也不是对未知重复的完整保证。

真实病例没有可用于身份的逐波真值，因此本轮不报告跨壁身份准确率。未找到匹配不能证明两壁绝无生理对应，尤其当显著筛选仅保留了不同局部范围时。

## 分母与单位

患者级候选率=统一候选数量/局部可观察分钟；未定对应显示相应条件范围。分母取原始测量区间的并集：至少一壁有3个相邻有效径向位置；安静时段计入，失去全部局部支持的时段不计入。两壁时长不相加，也不只使用显著活动持续时间。

这个分母是局部径向可观察支持，不等于整条宫颈—宫底始终可见。结果属于探索性显著活动候选密度，尚非已复核生理波频率。旧版分壁“条数”主表已由患者级表取代；原字段仅作为来源保存。

临床正反单位为次/分，解剖方向和是否对应保存视频仍未确认。主表保留临床原始正反值及两列数值合计，与患者级候选率并列；不把临床合计自动当去重事件数，不计算ICC或临床准确率。

## 必要验证

复用现有归一化试验中的12组已知条件：三张纹理×两个方向×单强波/20秒双强波。不新造fixture，不调关联容差。

- 6组单波：两壁各一份的2条来源均汇成1个患者候选。
- 6组双波：两壁各两份的4条来源均汇成2个患者候选。
- 12/12条件均保留每个已知身份一次，没有将两个不同真值活动合并。它是共享图像/信号模型上的功能验证，不是12名独立患者的准确率。
- 三项接口检查覆盖不同壁run ID仍可对应、时间分离不合并、一对多竞争不强配、方向冲突保留，以及观察时长并集包含安静时段而不重复计时。
