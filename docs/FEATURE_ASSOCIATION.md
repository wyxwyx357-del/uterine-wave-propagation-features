# 五项固定特征的探索性关联分析

此步骤分析临床妊娠关联，不重新定义特征，也不替代测量误差、重复性或预测验证。仅在授权结局分析后使用，所有患者数据和输出保留本地。

```powershell
python -m experiments.feature_association `
  --cohort <此前波次数AUC的analysis_cohort.csv> `
  --output <本地输出目录> --bootstrap 1000
```

固定五项：前壁主幅度、后壁主幅度、显著传播活动频率、既有单block ER CC、既有单block ER MSE。逐项分析，不将CC/MSE捏合为新指标；不平均多block，不使用未冻结的患者级ER。MSE可用但CC未定义的单block病例可进入MSE自己的分析，二者样本量明确分开。

1. 组间描述：每项全部可用值的均值、SD、中位数、四分位数和缺失数；妊娠组减非妊娠组的均值差及1000次患者聚类bootstrap区间。重复检查随患者整体抽样。
2. 线性关联：特征及固定七个临床变量的完整病例，不进行单次中位数插补推断；同一特征的未调整/调整模型使用完全相同病例。无惩罚Logistic MLE，OR按该完整样本的一个SD增加解释。标准化临床变量只改善数值条件，不改变调整内容。
3. 不确定性：患者得分向量先聚合，再计算Hessian逆矩阵夹心协方差；使用CR1系数G/(G−1)×(N−1)/(N−K)，Wald正态区间及卡方检验。对应[公开实现公式](https://www.statsmodels.org/stable/_modules/statsmodels/stats/sandwich_covariance.html)。不把每次检查当作互相独立患者。
4. 非线性：每项仅增加一个预先固定的z²项，与z同时入模；不搜索样条结点、分组、截点或最佳频率。分别报告曲率1自由度检验和(z,z²)联合2自由度检验。线性、曲率、联合检验各在预定五个特征内作BH校正，全部显示。
5. 曲线：只画观察范围内相对该特征中位数的调整OR和逐点95%区间，不输出“最优值”，不把优势比称为妊娠概率倍数。

这是已经看过先前AUC后固定的本轮探索方案，并非事前注册或独立验证。不同特征的完整病例和缺失机制不同，不能按OR大小直接排名；既有波计数的误报/漏检限制不变。关联不等于因果作用或个体预测价值。

必要测试：`python -m unittest tests.test_feature_association -v`，验证可解析2×2表的OR与方差、重复同一患者数据不会虚增独立精度，以及BH校正。另在本地用sklearn独立的无惩罚Logistic拟合核对全部五个实际调整模型系数。未修改追踪或冻结特征代码。

输出：protocol、组间表、均值差、OR/检验表、逐模型收敛及协方差审计、二次曲线、Excel、图和报告。未计算新的AUC、未调阈值或特征参数。
