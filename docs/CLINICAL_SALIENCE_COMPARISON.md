# 临床表与固定0.6候选的同次检查对照

2026-11-19用户授权用已有临床表对照，也可提供页面自行查看。用户已确认临床正反记录单位为次/分；本次再次确认，**不确定这些记录是否针对保存下来的同一视频**。正反的解剖方向仍未确认。

## 执行范围

- 只读既有工作簿，沿用match_clinical_wave_reference.py的白名单字段：视频编号、视频时间、视频时长、临床检查编号、临床记录时间、正反蠕动记录。不使用妊娠结局，不改工作簿。
- 12例按视频研究编号和视频日期均唯一匹配到临床记录。唯一匹配不能证明观察时段完全一致。
- 沿用既有0.6显著性结果，不修改A0、归一化范围、门槛、事件关联或特征定义，不按临床数值调整候选。
- 临床两列仍为次/分；程序显示前后壁整段显著候选条数及其中方向候选条数。**不将两壁相加当独立波次数，不把候选条数除时长伪装成正式频率。**
- 正反两列的数值合计只作为原表字段合计，不自动视为去重后的独立事件频率；缺失/非数值/多重匹配保持未确定，不当零。

## 已得到的信息

12例中，临床正反均为零的2例，非零10例。

| 描述性对照 | 程序有显著活动候选 | 程序无显著活动候选 |
| --- | ---: | ---: |
| 临床正反记录均零 | 1 | 1 |
| 临床有非零记录 | 9 | 1 |

| 描述性方向候选对照 | 程序有显著方向候选 | 程序无显著方向候选 |
| --- | ---: | ---: |
| 临床正反记录均零 | 0 | 2 |
| 临床有非零记录 | 8 | 2 |

两表的对象不同：显著局部活动可以没有传播方向。上述为检查级记录与固定程序输出的对应，不是视频级敏感度、特异度或准确率。临床记录有活动而程序为零、以及临床记零而仍有局部候选的情况，均可在对照页直接查看原始片段；不预先判定谁对谁错。

没有计算ICC：临床与程序目前既非同一已确认观察时段，也尚未得到相同事件定义下的正式频率。直接把每分钟临床数与整段候选数计算ICC会混用单位与测量对象。

## 输出与复现

```bash
python experiments/match_clinical_wave_reference.py \
  --workbook data/clinical.xlsx \
  --cohort-review outputs/cohort_wave_review_20261118_v1 \
  --output outputs/clinical_salience_comparison/reference --record-unit per_minute

python experiments/compare_clinical_salience.py \
  --reference outputs/clinical_salience_comparison/reference \
  --output outputs/clinical_salience_comparison
```

输出本地index.html、comparison.csv、cases.json、summary.json和provenance。页面同列临床记录、Excel行号、视频时长、两壁候选数，提供原视频、归一化对照图及22条显著候选的原视频证据时段。复用原1倍速文件，不重新编码、不另行裁剪上传；用户可按需查看，不要求逐条补医学标签。

候选时段是来源相位支持范围，不是已经确认的完整波持续时间；方向也仍是原候选方向。页面没有将原始A正负标成传播方向。
