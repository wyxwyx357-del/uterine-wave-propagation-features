# A0 失追后的位姿重置候选

`python -m uterine_wave.cli track ... --experimental-pose-reset` 将位姿重置限定在径向 inner 点。常规 `track` 与冻结批处理继续执行 A0 的旧纹理恢复。实验开关需要输入位姿文件含 `pose_epoch` 和 `pose_valid`。

每次到达既有重试时刻，先用最后可靠帧的纹理尝试匹配。该匹配失败时，若参考帧和当前帧位姿有效、处于同一位姿段，且预测位置在画面内，则把位姿预测位置作为候选新点。下一原生帧使用同一 LK、前后向误差和 NCC 条件确认，同时检查该帧位姿有效且仍在同一位姿段。确认失败继续遵循 A0 的重试间隔。

确认成功后沿用解剖槽位编号，开启新轨迹段。种子位置从下一帧确认后回写，种子帧的 `step_valid` 为 `False`，第一步有效位移为种子帧到确认帧。失追缺口保持缺失。`pose_reset_attempted` 标记候选种子，`pose_reset_seed` 标记确认后的种子，两者都落在种子帧。前后向误差和 NCC 记录在确认帧。这里的确认衡量相邻帧图像匹配，解剖位置还要在原图复核。分割轮廓可作为人工复核参考。

此前短片对照在预定失追帧直接初始化。本分支把相同的位姿放点方式接入 A0 的既有重试时刻，因此实际开始恢复的帧可能不同。网页审查后应先检查默认 A0 输出能否复现、旧纹理恢复优先级、下一帧确认与缺口处理，再对相同病例比较原图定位、漂移、有效支持和再次失追时间。建议先用同一参数做开发验证，再验证可用点对和特征误差。
