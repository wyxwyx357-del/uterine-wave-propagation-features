# 计算定义与接口

## 坐标、采样和时间

所有种子及轨迹为处理图上的浮点 `(x,y)`。LabelMe 坐标采用原流程 `point * coordinate_scale`，默认 0.5，不额外应用半像素中心修正。图像缩放与标注缩放必须相同。

两壁按端点到宫颈/宫底的距离确定顺序，在各自实际折线弧长的相同比例处采样。初始化的几何重采样不是对测量轨迹插值。径向外点沿局部壁法向向内膜腔外侧移动 21 px；窄带是两壁间 0.25/0.5/0.75 的几何插值，不能当作自动分割出的亮线中心。

`grid['A_points']` 按壁/纵向位置/内外点排列；`A_pair_ids` 为 `(2,N,2)`。`grid['B_points']` 按曲线/纵向位置排列；`B_curve_ids` 为 `(3,N)`。追踪输入明确为 `vstack([A_points,B_points])`，B 的索引在 B 子数组内部计数。A 保存各自壁弧长位置，B 保存各曲线自身实际弧长。

## 轨迹字典

| 字段 | 形状 | 含义 |
|---|---|---|
| `positions` | T×K×2 | 图像坐标；缺失 NaN |
| `corrected` | T×K×2 | 通过对应姿态校正后的坐标 |
| `time_s` | T | 真实采集时间，严格递增 |
| `target_valid` | T×K | 当前位置有支持；第 0 帧来自给定种子，不代表已做动态 QC |
| `step_valid` | T×K | 上一帧到本帧可用于连续运动计算；第 0 帧为 false |
| `segment_id` | T×K | 轨迹段；缺失 -1，重定位确认后换新段 |
| `pose_epoch` | T | 背景校正阶段，同段内共享参考；Python 输入未提供时声明为单一阶段 |
| `poses` | T×3×3 | 图像→校正参考仿射姿态 |
| `target_ncc` / `target_fb` | T×K | 原灰度块相关 / 前后向像素误差 |
| `reanchor` / `recovery_attempted` | T×K | 重定位确认 / 尝试标记 |
| `reject_reason` | T×K | 定位/QC 状态 |

`track_segments` 不估计背景，要求提供姿态。默认恢复每 4 个原生帧尝试一次：从最后参考块定位，下一原生帧匹配成功才回填该重定位种子，并标记新段。原始参考并不证明重定位后材料身份完全相同，因此段边界不用于连续形变。

定位：局部对比增强，sigma=5，CUDA LK 21×21，max_level=3，30 次迭代。QC：原灰度 NCC≥0.75、STD≥2、FB≤0.75 px。这些是当前项目工程设置，不是临床准确性的充分条件。

## A：径向相对长度变化率

同壁内外点距离为 L。间隔 h 帧：

`A(t) = [L(t)-L(t-h)] / L(t-h) / [time(t)-time(t-h)]`

单位 s⁻¹，正值为点对长度增加。它是有限时间间隔的相对伸长率，不是严格瞬时导数，也不声称与 Huang 的 RSR 实现逐项一致。旧rate_A/compute_maps默认h=8；当前compute_spacetime及CLI默认约2 s物理跨度，保存实际dt。

## 真实时空图的坐标与显示约定（2026-11-17）

`s=grid['u']` 是首帧完整已标壁路径的归一化弧长，宫颈侧端为0、宫底侧端为1。前后壁分别归一化，保持显式wall/section/pair索引。端部裁切后不把保留点重新扩展成0–1；稀疏有效子区也保留原s坐标。无毫米标定的事件传播速度以归一化路径/秒表示，两壁路径物理长度可能不同。

真实复核记录区间起止、实际dt与中心时刻。`compute_maps`原API的`time_s=t[h:]`仍为右端时间，不静默改变；新复核输出另存`interval_start_s`、`interval_end_s`和`interval_center_s`，图用明确的中心时刻。A为s^-1；区间应变epsilon=A*实际dt为无量纲，百分数图再乘100，二者分别命名。

分析mask要求inner/outer在整个区间所有步骤有效、各自segment不变、pose epoch不变及校正位置有限；有pose_valid时还须全区间姿态有效。缺失不填、不跨段、不沿空间补邻点。追踪显示有效、形变区间有效与传播可分析支持分别保留，不互相替代。

统一入口为`compute_spacetime(tracks, grid, interval_s=2.0)`：按原生帧间隔选择最接近目标跨度的hop，返回A、epsilon、valid_mask、s、interval_start_s/end_s/center_s/dt_s和实际hop；不补帧，不产生事件计数。非均匀采样时仍保留每个区间的实际dt，不宣称全部跨度相同。旧compute_maps的默认hop和time_s语义保持兼容。interval_support现在在输入提供pose_valid时统一消费该字段，并避免修改原target_valid数组。

本地开发缓存按统一入口复算。旧缓存缺少独立pose_valid时应记录这一限制，不以全True掩码代替质量字段。

## B：曲率变化率

每条窄带曲线以初始实际弧长为自变量，逐位置对 5 个相邻种子拟合二维二次曲线。曲率为 `(x'y''-y'x'')/(x'^2+y'^2)^(3/2)`，再计算 `[k(t)-k(t-h)]/dt`。单位为 `(处理后像素·秒)⁻¹`。两端各排除 2 个位置；参与 5 个种子都须有连续支持。

A/B 需要区间内每一步有效、段编号一致、校正阶段一致；不只看区间两端。缺失位置和不满足连续性的结果保留 NaN。两条路线量纲不同，不能比较原始 RMS 来断言谁更强。

## 方向 ER

`direction(y,time_s,space)` 输入完整的连续时空块。空间按宫颈→宫底递增；时间 FFT，空间用实际弧长坐标的加权离散傅里叶投影，频带 0.5–5 次/分。`ER=(Eforward-Ebackward)/(Eforward+Ebackward)`。无能量时返回 `None`。

方向结果同时返回`directional_rms`和`directional_band_energy_fraction`。前者是按时间样本数和空间列数归一化后的方向谱RMS，保留输入A的s⁻¹单位，可与相同处理的刚体对照比较；后者是0.5–5次/分频带能量中非零空间方向能量的比例。两者只描述活动强度/支持，不改变ER，也不作为自动事件门槛。

## 区间径向形变幅度

当前生理解释为“径向伸缩活动幅度”，受测量跨度及运动快慢共同影响。固定区域/时段患者汇总和已复核事件接口见[当前特征定义](FEATURE_DEFINITIONS.md)。原始SD仅作QC，事件内SD不等同患者频带SD。

`amplitude.band_limited_sd(epsilon,time_s)`在完整连续块内对每个径向点对去均值，以FFT保留0.5–5次/分，再返回各点对带内SD。区域主汇总为逐点对带内SD的算术均值；无滤波SD同时保留为QC。输入是无量纲区间应变epsilon，因此百分数输出乘100。该量称“频带内区间应变SD”，不是单次事件峰值；缺失不填，跨段块不能输入。

返回频率分辨率和时长；60 s 的分辨率约 1 次/分，不因频带下限写 0.5 就具有 0.5 的分辨能力。数值能量底只处理近零，不是已验证的噪声阈值。不能用 ER 单独检测波或计数，更不能把每个候选频率当成真实每分钟事件数。

`describe` 用同一有效范围计算测量/参考误差；仅对全时间完整支持的最长连续空间块计算 ER，且报告使用列号。该辅助规则用于当前对照诊断，不要求真实研究所有点全程有效。真实数据可选支持明确的局部时空段。

## 模式速度与双壁模式相似度（2026-11-17）

`mode_velocity(y,time_s,s)`复用同一谱和ER约定，在两个方向的正时间频率半平面分别求谱峰，`v=-ft/fs`。s为完整壁归一化路径时单位为路径/秒。两方向均保留；不是逐事件到达速度或事件频率。输出谱格点分辨率、可选单元数、最低非零空间频率峰和Nyquist峰诊断；不把谱峰存在当作有波证明。

`analyze_modes(spacetime,window_s=20,step_s=1,regions=None)`在每个原生时间窗的连续完整空间块上计算，保留全部支持块；不跨缺口拼接、补值或混合不同ROI汇总。至少3列是数值规则，不是生理门槛。时间步长取最接近的原生帧数并记录实际值。双壁ER仅比较同一时段同一空间块，按固定块和连续时间组计算零时延CC及MSE，称模式相似度候选。它与事件级协调性分开。

当前20秒窗在0.5–5 cpm内仅有一个正时间频率格点；3列空间块每方向仅有一个可选谱单元。此时谱速度量化严重，峰能量占比1也不能作为高可信证据；结果保留为候选，不据此给患者传播速度排名。

## 2026-11-17 连续模式速度与物理跨度入口

`mode_velocity(..., refine=True)`显式启用候选：在完整时空块上联合拟合两个反向平面波。每个分量有连续的时间频率f、空间波数k和sin/cos系数；约束f位于既有0.5–5 cpm范围，两个k符号相反，速度仍为`-f/k`。各位置的常数和线性趋势作为干扰项，同时从数据与模型投影出去。它使用多位置的相位关系，不是R2单点主频，也不承担事件计数。

本实现为项目测量优化，不声称论文采用了同一连续拟合。原生样本、A、epsilon、ER和双壁ER协调性定义不变。默认`refine=False`保留旧离散谱候选；启用新候选时，方向字典中`grid_peak`完整保存旧结果，`velocity`、`temporal_frequency_hz`、`spatial_frequency`对应新拟合。原顶层谱峰诊断仍描述离散谱，不是新拟合可信度。真实视频存在参数边界和未收敛窗口，因此本轮不将新候选提升为默认路线，旧粗谱速度同样不升级为已验证真实波速。

共同`velocity_fit`记录去线性趋势后残差能量比例、优化收敛和分量矩阵条件数；各方向记录参数边界、分量能量比例和状态。分量能量比例不可直接相加为1，因为存在交叉项。数值近零分量、空间均匀分量或数值上不可分离的反向分量返回速度None；不把None回填为旧速度。频率边界和残差是诊断，不是新增生理门槛。连续估计不增加20秒观测本身的信息量，拟合好也不自动证明存在真实传播事件。

`analyze_modes(...,refine_velocity=True)`显式传递新候选策略，默认False；复用同窗同空间块计算，避免为双壁协调性重复拟合速度。缺失、段边界和原ER保持不变。

`features`命令默认走`compute_spacetime(...,interval_s=2.0)`；`--interval-s`可明确指定物理跨度，与旧`--hop`互斥。旧`compute_maps`与显式`--hop`继续提供右端time_s及A/B输出。新默认输出保存原区间起止、中心、实际dt与hop，不能与旧time_s隐式混用。

`track_segments(...,pose_valid=None)`新增可选位姿有效掩码，提供时检查长度并原样归档；不改变LK匹配/恢复路线，不把姿态有效与点匹配有效混为一谈。CLI从位姿NPZ读取该字段并传入，后续interval_support按已有规则屏蔽整个受影响区间。

## 当前默认跨度（覆盖历史默认说明）

`DEFAULT_PROPAGATION_INTERVAL_S=2.0`用于compute_spacetime与CLI，`SENSITIVITY_INTERVAL_S=.96`为显式对照。旧compute_maps(hop=8)保持兼容，不代表当前传播默认尺度。输出A、epsilon的通用键保持兼容；文件名/特征表使用A_rate_2s、epsilon_2s与0p96s分开命名。实际dt始终以interval_dt_s为准，2s是名义尺度，不写死hop。
