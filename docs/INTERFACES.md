# 计算定义与接口

## 坐标、采样和时间

所有种子及轨迹为处理图上的浮点 `(x,y)`。LabelMe 坐标采用原流程 `point * coordinate_scale`，默认 0.5，不额外应用半像素中心修正。图像缩放与标注缩放必须相同。

两壁按端点到宫颈/宫底的距离确定顺序，在各自实际折线弧长的相同比例处采样。初始化的几何重采样不是对测量轨迹插值。径向外点沿局部壁法向向内膜腔外侧移动 21 px；窄带是两壁间 0.25/0.5/0.75 的几何插值，不能当作自动分割出的亮线中心。

`grid['A_points']` 按壁/纵向位置/内外点排列；`A_pair_ids` 为 `(2,N,2)`。`grid['B_points']` 按曲线/纵向位置排列；`B_curve_ids` 为 `(3,N)`。追踪输入明确为 `vstack([A_points,B_points])`，B 的索引在 B 子数组内部计数。A 保存各自壁弧长位置，B 保存各曲线自身实际弧长。

## 轨迹字典

| 字段 | 形状 | 含义 |
|---|---|---|
| `positions` | T×K×2 | 图像坐标；缺失 NaN |
| `corrected` | T×K×2 | 通过对应姿态校正后的坐标 |
| `time_s` | T | 真实采集时间，严格递增 |
| `target_valid` | T×K | 当前位置有支持；第 0 帧来自给定种子，不代表已做动态 QC |
| `step_valid` | T×K | 上一帧到本帧可用于连续运动计算；第 0 帧为 false |
| `segment_id` | T×K | 轨迹段；缺失 -1，重定位确认后换新段 |
| `pose_epoch` | T | 背景校正阶段，同段内共享参考；Python 输入未提供时声明为单一阶段 |
| `poses` | T×3×3 | 图像→校正参考仿射姿态 |
| `target_ncc` / `target_fb` | T×K | 原灰度块相关 / 前后向像素误差 |
| `reanchor` / `recovery_attempted` | T×K | 重定位确认 / 尝试标记 |
| `reject_reason` | T×K | 定位/QC 状态 |

`track_segments` 不估计背景，要求提供姿态。默认恢复每 4 个原生帧尝试一次：从最后参考块定位，下一原生帧匹配成功才回填该重定位种子，并标记新段。原始参考并不证明重定位后材料身份完全相同，因此段边界不用于连续形变。

定位：局部对比增强，sigma=5，CUDA LK 21×21，max_level=3，30 次迭代。QC：原灰度 NCC≥0.75、STD≥2、FB≤0.75 px。这些是当前项目工程设置，不是临床准确性的充分条件。

## A：径向相对长度变化率

同壁内外点距离为 L。间隔 h 帧：

`A(t) = [L(t)-L(t-h)] / L(t-h) / [time(t)-time(t-h)]`

单位 s⁻¹，正值为点对长度增加。它是有限时间间隔的相对伸长率，不是严格瞬时导数，也不声称与 Huang 的 RSR 实现逐项一致。默认 h=8；0.12 s 原生间隔时为 0.96 s，其他间隔按真实时间计算。

## B：曲率变化率

每条窄带曲线以初始实际弧长为自变量，逐位置对 5 个相邻种子拟合二维二次曲线。曲率为 `(x'y''-y'x'')/(x'^2+y'^2)^(3/2)`，再计算 `[k(t)-k(t-h)]/dt`。单位为 `(处理后像素·秒)⁻¹`。两端各排除 2 个位置；参与 5 个种子都须有连续支持。

A/B 需要区间内每一步有效、段编号一致、校正阶段一致；不只看区间两端。缺失位置和不满足连续性的结果保留 NaN。两条路线量纲不同，不能比较原始 RMS 来断言谁更强。

## 方向 ER

`direction(y,time_s,space)` 输入完整的连续时空块。空间按宫颈→宫底递增；时间 FFT，空间用实际弧长坐标的加权离散傅里叶投影，频带 0.5–5 次/分。`ER=(Eforward-Ebackward)/(Eforward+Ebackward)`。无能量时返回 `None`。

返回频率分辨率和时长；60 s 的分辨率约 1 次/分，不因频带下限写 0.5 就具有 0.5 的分辨能力。数值能量底只处理近零，不是已验证的噪声阈值。不能用 ER 单独检测波或计数，更不能把每个候选频率当成真实每分钟事件数。

`describe` 用同一有效范围计算测量/参考误差；仅对全时间完整支持的最长连续空间块计算 ER，且报告使用列号。该辅助规则用于当前对照诊断，不要求真实研究所有点全程有效。真实数据可选支持明确的局部时空段。
