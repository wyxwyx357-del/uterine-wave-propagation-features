# 可观察的不完整相位与片段归属：沙盒候选

该候选实现“保留能测部分→提出片段归属→保留正式输出复核门控”，仅供配对实验，未接入正式CLI、`events.py`或`patient.py`，不替换默认波候选，不改变A0、幅度和ER。

## 边界相位

沿用原连续有效段、滤波、绝对噪声参照、相邻连接与配对公式。原来接触块首尾就整段删除的相位，改为：

- 峰值确实位于已观察相位内部时保留，标记首端/尾端不完整。
- 峰值只出现在边界、无法确定峰是否被完整拍到时，保存为未解决边界片段，不虚构峰值或加入峰值连接。
- 记录连续段、原生空间位置、观测起止和各节点边界状态。不补缺失、不跨失追段，不要求一定拍到整个回落。

`observed_start_s/end_s`是实际观测到的滤波相位结构范围；`structure_start_s/end_s`在相应边界未知时为空。这些不是完整生理收缩起止时间。各位置的相位支持另存于`local_phase_support`，最小/最大时间构成的显示包围框不保证所有位置在整个框内都有效，不能直接据此跨缺口计算幅度。

## 片段归属提案

若单相片段存在唯一互补配对，与已有双相结构共享相反相位、阶段先后一致、方向一致、空间支持不重叠，则保留各段测量，提出共享活动身份。只处理整个单相片段都被覆盖的情况，不隐去其余未归属支持。

多个可能归属、局部阶段重复占用或方向冲突保持待定。共享身份只是`identity_reviewed=False`的提案，不能直接当作已确认独立波。两壁不在此自动融合，不能把两壁提案数直接相加当患者波数。

## 防止“保留信息”变成“自动增加独立波”

直接保留边界峰会产生新的方向结构，因此实验将输出分层：

1. `fragments`：可观察测量片段及不完整状态。
2. `ownership.existing_candidate_groups`：原有候选的归属提案。使用精确的“相位符号、原生位置、原生峰时刻”确认原支持是否完整包含在新结构中；多解保持原候选独立待定，不丢原信息。
3. `ownership.additional_support_groups`：尚不能对应已有候选的补充证据，不自动升级为新独立事件。

所有原候选必须恰好保留一个可追溯位置；新旧滤波数组要求逐值一致。支持归属的变化不等于真实检出准确率变化。正式`event_count`和`event_frequency_cpm`始终为空，后续仍需独立活动身份验证。

真实病例另导出三张UTF-8 CSV：`fragment_measurements.csv`记录各段已测范围、未知边界及来源；`event_identity_proposals.csv`记录共享身份提案且复核状态为假；`patient_event_status.csv`记录病例级进度，正式次数和次/分保持空值。CSV中的结构边界仍是滤波相位证据，不是已验证的完整生理收缩时长；这些是实验检查表，不是新增AUC输入特征。

同壁候选的本地ID与壁号一起使用，来源引用同时保留原`wallN_candidate_XXX`形式。跨壁同一次活动的确认和正式汇总接口没有在此自动改变。

## 统一回测

```bash
python experiments/test_partial_phase_cohort.py --review-root outputs/cohort_review --controls-root outputs/frozen_controls --noise-reference outputs/noise_reference.json --prior-controls outputs/prior_control_audit.json --output outputs/partial_phase_trial
```

覆盖全部预选病例、原三纹理×四条件、固定噪声的27组传播幅度/同步活动对照；无患者专用参数，无阈值扫描，无结局输入。检查原基准复现、源文件哈希、滤波不变、局部支持、相位缺口、已知方向保留及额外结构，不能只凭候选数减少决定采用。

本入口顺序执行，临时替换实验调用中的局部函数，退出即恢复；不是并行或生产调用接口。

这个候选不处理滤波额外振荡的独立事件归属问题，也不自动把单相、短路径或低幅度活动删除。患者视频、缓存、提案和结果仅留本地。
